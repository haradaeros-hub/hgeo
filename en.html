01 / TOOLKIT

FROM QUESTION TO MAP.

Tools to get things done. Guidance to learn along the way. Choose the path that fits your project.

01
OPERATIONAL COPILOT

Set the ground.

Google Satellite basemap, temporary point, line and polygon layers, CRS selection, buffers in metres or kilometres, and clearing feature selections.

02
LEARNING

Move forward with guidance.

Nine guides: a QGIS tour, Shapefile preparation for SISLA, Clip, intersection, difference, spatial joins, merging layers, watersheds and batch reprojection. These guides walk you through operations in QGIS.

03
ANALYTICAL LAB

Read beyond the visible.

NDVI, EVI, SAVI, NDWI, MNDWI, NDMI, NDSI, BAI, NBR, NBR2, NDBI and UI. Use loaded Sentinel-2 or Landsat 8/9 bands, or search for and download Sentinel-2 data.

04
IMAGERY & TERRAIN

Give data a shape.

True-colour and false-colour composites, RGB virtual rasters and elevation colouring. Copernicus DEM, an OpenTopography fallback with an API key, and SIRGAS 2000/UTM reprojection.

05
HYDROLOGY

Follow the water.

Flow direction and a drainage network controlled by a threshold, outlet selection on the map, and delineation of one or more watershed polygons using GRASS and GDAL.

06
CHANGE ANALYSIS

See what changed.

Two Sentinel-2 acquisitions, zoomable previews, quality masking, a common grid and B − A differences. Outputs include PDF, date and difference GeoTIFFs, CSV statistics and JSON provenance.

02 / WORKFLOW

CHOOSE YOUR PATH.

Four workflows. Pick one for your task; they do not need to run in sequence.

01

Operational

  1. Choose an action or a guide
  2. Set parameters or follow the steps
  3. Work with layers in your project
02

Laboratory

  1. Choose a category and an index
  2. Load bands or download Sentinel-2 / DEM
  3. Assign inputs and process
  4. Explore the raster or composite
03

Watersheds

  1. Select or download a DEM
  2. Set the threshold and generate drainage
  3. Mark the outlet on the map
  4. Generate the watershed polygon
04

Change analysis

  1. Set the area, dates and cloud limit
  2. Inspect acquisitions A and B
  3. Choose indices, grid and quality
  4. Generate PDF + GeoTIFF + CSV + JSON

05 / FIELD NOTES

BEFORE YOU START.

Report an issue ↗
What has been validated?+

Importing the plugin, opening both modes and the report window, menu integration, window reuse, unloading, and one NDVI/NoData case using QGIS 3.40.15. Downloads, full PDF generation and all workflows with real data still need validation.

What does it depend on?+

QGIS and the processing providers required by the operation, including GDAL and GRASS. Downloads need internet access and service coverage. The alternative OpenTopography method requires an API key.

How can I report a problem?+

Use GitHub Issues and include your QGIS version, reproduction steps and the error message. Remove passwords, tokens and private information from attachments.

How do I update the plugin?+

Wait for tasks to finish, close the tools, disable the plugin and install the new ZIP through the plugin manager. Restart QGIS if necessary.
